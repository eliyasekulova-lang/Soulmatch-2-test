# Product Requirements (MVP)

## Goal
Create a mobile-first matchmaking and social discovery app that combines astrological birth-chart data with psychological profiling to produce personalized romantic and friendship recommendations.

## Target Users
- Astrology-curious Gen Z and millennials
- Singles seeking meaningful partners
- People seeking aligned friendships

## Launch Strategy
- Pilot city: Toronto
- Product remains worldwide-ready with geocoding/timezone support

## MVP Scope
1. Onboarding with precise birth data (date, time, place)
2. AstroVector generation and storage
3. Matching engine (vector similarity + synastry heuristics)
4. Dual-mode recommendations (Romance / Friendship)
5. Match cards and basic messaging
6. Premium gating for advanced synastry and timing

## Key User Flows
- Sign up -> Birth data -> Preferences -> Mode select -> Matches -> Chat
- Switch mode (romance/friendship)
- View compatibility highlights

## Success Metrics
- Activation rate: complete onboarding + view first matches
- Match-to-chat conversion
- Premium conversion on reports

## Out of Scope (MVP)
- Payments
- Full ML personalization
- Video or audio features
- Group matching
